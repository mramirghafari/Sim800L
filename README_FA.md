# SIM800L Control Center

نسخه بازطراحی‌شده پروژه `SIM800L_Flasher` با رابط Windows Forms راست‌چین.

## امکانات

- انتخاب خودکار پورت‌های COM و Baudهای رایج
- اتصال پایدار به SIM800L و انتظار صحیح برای پاسخ سریال
- نمایش مدل، نسخه firmware، IMEI، IMSI، ICCID، اپراتور، سیگنال، ثبت شبکه و وضعیت SIM
- ترمینال AT با لاگ زمان‌دار
- اعتبارسنجی فایل firmware و محاسبه SHA-256
- اجرای محافظت‌شده ابزار رسمی فلش سازنده
- مسدودسازی فرمان‌های شناخته‌شده نوشتن IMEI/NV

## ساخت و تست

```powershell
dotnet build
dotnet run --no-build -- --self-test
```

## نکته مهم

فرمان‌های `AT+QIMEI` و `AT+QCFG` مربوط به خانواده Quectel هستند، نه SIM800L. این نسخه تغییر یا جعل IMEI را انجام نمی‌دهد و شناسه را فقط برای عیب‌یابی می‌خواند. برای firmware باید فایل و ابزار رسمی دقیقاً سازگار با revision برد استفاده شود.
